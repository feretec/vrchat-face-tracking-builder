# Tabler Icons

Source: https://github.com/tabler/tabler-icons (MIT; see LICENSE.md).

The original SVGs are retained unchanged. PNGs are 96 x 96 transparent white
rasterizations of those SVGs (resvg_py 0.5.0) for Unity UI Toolkit, tinted to the text color
at runtime. No icon geometry was modified.
